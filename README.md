## Project Documentation

This section accompanies the Applied Web Project Part 1 submission for
COS10026 Web Technology Project, Group HD.

### Project overview
Community Connect is a fictional community and social services
organisation (allocated scenario G03). The site is a static recruitment
website built with HTML5 and CSS3 only, deployed via GitHub Pages.
