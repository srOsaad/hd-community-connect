# assets/

All image assets live here.

**Naming rules — these are not optional.** GitHub Pages runs on a
case-sensitive server; your laptop is not. `Logo.PNG` referenced as
`logo.png` works locally and 404s on the deployed site.

- lowercase only
- hyphens, never spaces or underscores
- descriptive: `team-photo.jpg`, not `IMG_4821.JPG`

**Size limits**

- Group photo (about.html): **under 300 KB** — this is a marked requirement.
- Everything else: keep under ~500 KB. Export JPEG at ~1200px wide,
  quality 75, and check the file size before you commit.

**Record the source.** Anything not made by us — stock photos, icons,
GenAI-generated images — must be credited in the Acknowledgements line
in the footer of every page.
